Assignment:
Project 2/5 | Designing an Airline Application | CS410P Joy of Coding Java and Android at PSU

Description:
This is Project 2 of 5 assigned in the Joy of Coding Java and Android at Portland State University. 
It consist of creating a TextDumper, which writes an airline and its flights to a specified file, 
and a TextParser, which reads the contents of a text file and checks if the airline name in the
file matches the airline name provided on the command line. If it doesn't, the program displays a
helpful error message. Additionally, the Project1 class (now Project2) has been refactored to 
reflect the assignment requirements, adding the -textFile filename option along with more modular
and efficent command line parsing. 

While refactoring my Project2 class, I gained experience in planning how to refactor code and
integrating it into an already existing codebase. I plan to continue refactoring throughout the
term to make the Project2 class functional and reusable for command line parsing that adds more
options to it. The development of the TextDumper and TextParser taught me how to interact with
files through the Java IO and NIO APIs, and the unit and integration testing taught me how to
verify that files are created and exist to ensure the program works as intended.
