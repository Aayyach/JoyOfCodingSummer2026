Project 3/5 | Designing an Airline Application | CS410P Joy of Coding Java and Android at PSU

Description:
This is Project 3 of 5 assigned in the Joy of Coding Java and Android at Portland State University. 
It consist of creating a PrettyPrinter, which writes an airline and its flights to a specified file, 
in a pretty format, or displays it to standard out if the filename is "-". Additional changes were 
made to the Airline, Flight, and unit tests to reflect these changes.  Additionally, the Project3 
class (now Project3) has been refactored to reflect the assignment requirements, adding the -pretty 
filename option along with more modular and efficent command line parsing. 

While refactoring my Project3 class, I gained experience in planning how to refactor code and
integrating it into an already existing codebase. I plan to continue refactoring throughout the
term to make the Project3 class functional and reusable for command line parsing that adds more
options to it. The development of the PrettyPrinter taught me how to interact with files and dates 
through the Java IO and LocalDateTime/LocalDate APIS, and the unit and integration testing taught 
me how to verify that files are created and exist to ensure the program works as intended.
