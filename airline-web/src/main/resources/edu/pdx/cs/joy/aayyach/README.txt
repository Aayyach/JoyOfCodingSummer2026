Project 4/5 | Designing an Airline Application | CS410P Joy of Coding Java and Android at PSU

Description:
This is Project 4 of 5 assigned in the Joy of Coding Java and Android at Portland State University. 
It consists of taking what was assigned through projects 1, 2, and 3 and using the code to interact 
with a webserver from our local machines using HTTP methods like GET, PUT, POST, and DELETE. Out of 
all of the assignments that have been assigned thus far, I will say this has been one of the most
challenging ones to complete. To successfully complete the assignment, you must make sure that you
understand the basics of the web, and how a server and client can interact with each other through
your code. 

Even while understanding the concepts, writing the code felt challenging for me since 
this is the first course I've taken where I've had the opportunity to write code for a client and
server to interact with each other. Nonetheless, I think that this was a very good learning
opportunity since we were able to refactor an existing codebase, which was the plain dictionary
style code, into code that supports airlines and flights. I'll defintely need more practice with
these concepts, especially in Java, but I had a lot of fun writing the code for this assignment 
and actually seeing how HTTP works through the GET and POST methods.
